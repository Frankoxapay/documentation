OxaPay is a cryptocurrency payment gateway that enables businesses to manage digital assets, receive and send payments, and exchange cryptocurrencies. Developers integrate through service-specific APIs rather than a single shared API key.

## From payment creation to credited funds

A merchant creates a payment, optionally registers a callback URL, and the customer completes it through OxaPay or the merchant's own interface. OxaPay credits completed funds to the merchant account and sends webhook updates so the merchant backend can synchronize the payment state.

## Everything you need to build with OxaPay

Complete these steps to authenticate, create your first payment, and handle status updates.

<Columns cols={3}>
  <Card title="1. Obtain your API keys" icon="key">
    Create the Merchant, Payout, or General API key in the OxaPay dashboard for the service you will call.

    [View authentication →](/quickstart)
  </Card>

  <Card title="2. Create a payment" icon="credit-card">
    Use the Merchant API Key to create a payment so a customer can pay and completed funds credit to your account.

    [Open quickstart →](/quickstart)
  </Card>

  <Card title="3. Handle webhook updates" icon="webhook">
    Register a callbackUrl when creating a payment so OxaPay can notify your backend as the payment status changes.

    [View webhooks →](/quickstart)
  </Card>
</Columns>
